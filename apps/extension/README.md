# Private Marketplace

A private extension marketplace for VS Code, for organisations that cannot use
the public gallery.

Extensions are distributed as **npm packages** carrying a `.vsix`, so whichever
registry you already run works as the transport: JFrog Artifactory, Sonatype
Nexus or Verdaccio — or a plain folder of `.tgz` files for air-gapped machines.

See the repository root for the format specification and architecture.
